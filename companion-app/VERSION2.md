# 安诊达陪诊员端 version2 版本说明

更新时间：2026-04-21 15:57:38 +08:00

版本标识：version2

## 本版本主要更新

1. 完成陪诊员端 APP 基础页面
   - 工作台：首页展示今日待处理、在线状态、进行中订单、收入和完成单数。
   - 待接单页：展示可抢订单，支持查看详情和抢单。
   - 进行中订单页：展示已接订单，并支持按阶段推进。
   - 订单详情页：展示订单完整信息和操作按钮。
   - 我的页：展示陪诊员资料、认证状态、评分、统计信息。

2. 接入真实订单数据
   - 通过 uniCloud 云函数读取用户端创建的真实订单。
   - 支持陪诊员抢单。
   - 支持订单状态更新并同步到用户端。

3. 完成订单阶段流转
   - 阶段包含：已接单、正在前往、已接到用户、已到达医院、服务中、已完成。
   - 陪诊员端更新状态后，用户端订单页和追踪页可刷新查看最新状态。

4. 增加接到用户核验能力
   - 订单详情页支持可选上传接到用户核验图片。
   - 核验图片不强制上传，方便演示流程不中断。
   - 已上传图片会保存到订单数据中，供用户端查看。

5. 优化云函数资源使用
   - 陪诊员端只在页面显示、手动刷新或点击操作时调用云函数。
   - 不做持续高频轮询，降低云函数 GBs 消耗。
