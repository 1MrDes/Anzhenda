# 安诊达 version2 版本说明

更新时间：2026-04-21 15:57:38 +08:00

版本标识：version2

## 本版本主要更新

1. 完成用户端真实订单闭环
   - 接入 `az_orders` 数据集合。
   - 支持真实创建订单、支付状态更新、订单列表读取、订单详情读取。
   - 首页、订单页、支付页、追踪页可读取真实订单数据。

2. 完成陪诊员端 APP 基础闭环
   - 新增陪诊员工作台、待接单、进行中订单、订单详情、我的页面。
   - 支持陪诊员查看待接订单、抢单、查看订单详情。
   - 支持陪诊员按服务阶段更新订单状态。

3. 优化订单状态同步流程
   - 订单阶段统一为：待支付、待接单、已接单、正在前往、已接到用户、已到达医院、服务中、已完成。
   - 用户端订单页和追踪页按真实订单阶段展示。
   - 修复用户端提前显示“已接单 / 正在前往”的问题。
   - 新增“陪诊员已接到用户”阶段。

4. 增加接到用户核验能力
   - 陪诊员端订单详情支持可选上传核验图片。
   - 用户端追踪页可查看陪诊员上传的核验图片。
   - 图片上传不作为强制条件，避免阻断演示流程。

5. 优化云函数资源使用
   - 用户端订单页支持下拉刷新订单状态。
   - 用户端追踪页支持下拉刷新订单状态。
   - 移除订单页和追踪页自动定时请求订单接口的逻辑。
   - 减少 `listOrders` 和 `getOrderDetail` 的自动调用次数，降低云函数 GBs 消耗。

6. 地图与首页体验优化
   - 首页地图模式接入真实定位和地图展示。
   - 订单追踪页显示用户位置、陪诊员位置、医院位置和距离信息。
   - 首页底部订单卡片改为：无订单时显示“目前暂无订单”，有订单时显示真实进行中订单。
   - 优化地图标记、地图提示、地图抽屉、大地图模式和导航栏遮挡问题。

7. 辅助功能与语音能力优化
   - 完成界面大小“大 / 超大”模式整合。
   - 完成语音助手显示开关、帮助中心、语音播报基础能力。
   - 优化语音播放离开页面自动停止。
   - 优化帮助中心播报内容，支持问题和说明分段播报。

8. 家庭协同功能
   - 我的页面服务设置调整为就诊人管理、家人绑定、家庭代办。
   - 支持当前就诊人全局联动。
   - 首页问候语、预约流程、订单流程读取当前就诊人信息。
