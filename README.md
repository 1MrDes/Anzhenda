# 安诊达三端毕业设计项目

本仓库为安诊达毕业设计最终版本源码归档，包含用户端、陪诊员端和管理员端三个独立 uni-app 项目。

## 目录说明

- `user-app`：用户端，面向患者及家属。
- `companion-app`：陪诊员端，面向陪诊服务人员。
- `admin-h5`：管理员端 H5 后台，面向系统管理员。
- `安诊达三端最终版本项目说明.docx`：最终版本项目说明文档。

## HBuilderX 导入方式

请分别导入三个子目录，不要直接把仓库根目录作为 uni-app 项目导入。

## 注意事项

`unpackage`、`node_modules`、本地 Git 目录和临时备份目录不纳入源码上传，可由 HBuilderX 或依赖安装流程重新生成。
